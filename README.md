# 🌊 AI-Driven Hyperspectral Image Analysis for Marine Ecosystem Monitoring

An AI-powered marine ecosystem monitoring system that uses **Hyperspectral Imaging (HSI)** and **Deep Learning** to classify marine environments, detect ecological threats, and generate real-time environmental insights.

---

## 📖 Overview

This project leverages Hyperspectral Imaging and Machine Learning techniques to monitor marine ecosystems by identifying:

- 🪸 Healthy Coral Reefs
- 🌿 Harmful Algal Blooms (HAB)
- 🌊 Polluted Water Regions
- ⚠️ Coral Bleaching

The system performs preprocessing, dimensionality reduction, deep learning-based classification, and visualizes the results through an interactive Flask web application.

---

## 🚀 Features

- Upload hyperspectral `.npy` files
- Automated data preprocessing
- PCA-based dimensionality reduction
- K-Means clustering for pseudo-label generation
- CNN-based marine ecosystem classification
- Interactive Flask dashboard
- Coral Health Assessment
- Water Quality Index (WQI)
- Harmful Algal Bloom (HAB) Risk Analysis
- Real-time prediction and visualization

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/your-username/AI-Driven-Hyperspectral-Marine-Monitoring.git
```

Move into the project

```bash
cd AI-Driven-Hyperspectral-Marine-Monitoring
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
